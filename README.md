## 📌 ১. প্রধান মডিউলসমূহ (Modules Implemented)

1. **Dashboard (সারাংশ ড্যাশবোর্ড):**
   - ক্যাশ ইন হ্যান্ড (Petty Cash), সিটি ব্যাংক, ডিবিবিএল ও বিকাশ/নগদ ব্যালেন্স।
   - ক্লায়েন্টের বকেয়া বিল (Receivables) এবং সাপ্লায়ার দেনা (Payables)।
   - চলমান স্টিল প্রজেক্ট এবং বাজেট ব্যবহারের ভিজ্যুয়াল প্রগ্রেস বার।
   - স্টিল মালামালের লো-স্টক ওয়ার্নিং বার।

2. **Accounting / জমা-খরচ ও ব্যাংক হিসাব:**
   - প্রতিটি লেনদেনে Date, Voucher No (`AE-RC-2026-XXXX`, `AE-PV-2026-XXXX`), পক্ষ, ক্যাটাগরি, প্রজেক্ট ও অ্যাকাউন্ট নির্বাচন।
   - ক্যাশ, ব্যাংক ও বিকাশ অ্যাকাউন্টের আলাদা খাতা।
   - **Inter-Account Transfer**: এক ব্যাংক বা ক্যাশ থেকে অন্য অ্যাকাউন্টে ফান্ড ট্রান্সফার সুবিধা।

3. **Project Management & Costing (প্রজেক্ট হিসাব):**
   - কোড (যেমন: `PRJ-2026-01`, `PRJ-2026-02`), সাইট ঠিকানা, চুক্তি মূল্য ও স্ট্যাটাস।
   - প্রজেক্ট-ভিত্তিক আয়, খরচ, মালামাল ও শ্রমের খরচ এবং নিট প্রফিট মার্জিন।
   - বাজেট বনাম বাস্তবিক খরচের ট্র্যাকিং।

4. **Steel Stock & Inventory (স্টিল মালামাল ও ইনভেন্টরি):**
   - MS Plate, I-Beam, Channel, Angle, Flat Bar, Pipe, Profile Sheet, Bolt-Nut, Electrode, Paint ইত্যাদি।
   - স্টক ইনওয়ার্ড (ক্রয়) ও প্রজেক্ট সাইটে স্টক আউটওয়ার্ড (ইস্যু) চালান।
   - ন্যূনতম স্টক অ্যালার্ট (Minimum Stock Alert) এবং স্টক ভ্যালুয়েশন।

5. **Employee & Salary (কর্মচারী ও মাসিক বেতন শিট):**
   - কর্মকর্তা ও শ্রমিক তালিকা, মূল বেতন, বোনাস, অগ্রিম কর্তন ও নেট পেয়াবল হিসাব।
   - ১-ক্লিকে নির্দিষ্ট ব্যাংক বা ক্যাশ অ্যাকাউন্ট থেকে বেতন প্রদান ও ভাউচার জেনারেট।

6. **Client & Supplier Ledgers (পার্টি লেজার ও খাতা):**
   - ক্লায়েন্ট ও সাপ্লায়ারদের পূর্ণাঙ্গ লেনদেন খাতা।
   - বকেয়া পাওনার জন্য সরাসরি **WhatsApp Payment Reminder** পাঠানোর বোতাম।

7. **Vouchers & Money Receipts (A4 প্রিন্ট):**
   - অফিসিয়াল মানি রিসিট (Money Receipt) ও পেমেন্ট ভাউচার (Payment Voucher)।
   - কথায় টাকার অংক (Amount in Words) এবং Prepared By, Checked By ও Approved By (Managing Director) সিগনেচার ব্লক।

8. **Reports & Excel Export (আর্থিক রিপোর্ট):**
   - দৈনিক ক্যাশ বুক, ব্যাংক বুক, লাভ-ক্ষতি বিবরণী (P&L)।
   - **১-ক্লিকে সম্পূর্ণ ডেটাবেস Excel (`.xlsx`) ফাইলে এক্সপোর্ট** করার ব্যবস্থা।

9. **Google Drive Cloud Backup & Security:**
   - গুগল ড্রাইভ অটোমেটিক ব্যাকআপ সংযোগ (OAuth 2.0)।
   - সম্পূর্ণ ডেটাবেস JSON ব্যাকআপ ডাউনলোড ও টেস্ট রিস্টোর করার নিরাপদ ফিচার।
   - ইউজার অ্যাক্টিভিটি অডিট লগ (Audit Trail)।

10. **iPhone Safari PWA (Add to Home Screen):**
    - আইফোনে কোনো অ্যাপ স্টোর ছাড়াই সাফারির মাধ্যমে Home Screen-এ যুক্ত করে ফুলস্ক্রিন নেটিভ অ্যাপের মতো ব্যবহার।

## 🚀 ২. কীভাবে রান করবেন (How to Run)

প্রজেক্ট ফোল্ডারে প্রবেশ করুন:
```bash
cd asia-engineers-accounting
```

লোকাল সার্ভার চালু করতে:
```bash
npm run dev
```
ব্রাউজারে ভিজিট করুন: `http://localhost:3001`

প্রোডাকশন বিল্ড তৈরি করতে:
```bash
npm run build
```
প্রোডাকশন প্রিভিউ দেখতে:
```bash
npm run preview
```
